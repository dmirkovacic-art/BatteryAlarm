# 🔋 Battery Alarm

A lightweight battery monitoring app for **Wear OS**, with companion notifications on an Android phone.

Developed and tested on **Xiaomi Watch 5 (Wear OS 6)** and **Redmi Note 14 Pro 5G**.

## Features

- 🔔 Battery alerts at **15%, 10%, and 5%**
- 🔊 Audible alarm and vibration on the smartwatch
- 📱 Battery warning notifications on the connected Android phone
- 🔄 Background battery monitoring
- ⌚ Automatic monitoring restart after watch reboot
- 🧪 Manual **TEST ALARM** button

## Project Structure

| Module | Description |
|---|---|
| `wear` | Wear OS application for battery monitoring and alerts |
| `mobile` | Android companion application for phone notifications |

## Technology

- Kotlin
- Android Studio
- Wear OS
- Android Wearable Data Layer API

## Project Status

**Functional prototype** — tested on physical devices.

The application is currently intended for personal use and further development.
